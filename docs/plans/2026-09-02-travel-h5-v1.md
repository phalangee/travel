# travel-h5 首版实现计划

> **执行说明：** 本计划由同一 AI 依序执行，任务粒度按「可独立验收的交付物」划分；每个任务完成后运行验证并提交 Git。

**Goal:** 构建移动优先的旅行行程静态站：主页（旅行列表+足迹）+ 行程页（按天划卡、行程/美食/准备三 Tab、地图/降级示意、PWA 离线），并以 2026 新疆北疆 13 天行程填充首份数据。

**Architecture:** 无构建纯静态站。页面（HTML/CSS/JS）与数据（JSON）彻底分离；高德 JS API 存在 Key 时渲染真实地图，无 Key 时降级为有序地点条+跳转高德链接；Service Worker 缓存 App Shell 与数据实现离线。

**Tech Stack:** 原生 HTML/CSS/JS(ES2020)、scroll-snap、高德 JS API 2.0（可选）、JSON、Service Worker/PWA。

**Global Constraints:**
- 移动优先：基准视口 375–430px 竖屏；正文 ≥16px；点击目标 ≥44px；桌面 >768px 内容限宽 720px 居中。
- 相对路径资源引用（站点部署在 `/travel/` 子路径）。
- 数据字段全部可选；坐标为高德系（GCJ-02），首版坐标为近似值，后续可精化。
- 新疆行程数据按 D1–D13 共 13 天；吐鲁番 2 晚（10.1、10.2），乌鲁木齐 3 晚（9.23、10.3、10.4）。

## Task 1: 项目骨架与配置

**Files:** index.html, trip.html, css/style.css（基础部分）, js/config.js, js/util.js, manifest.webmanifest, assets/icon.svg, sw.js, .gitignore

**Produces:**
- `CONFIG.amapKey`（空串 = 降级模式）
- util: `getQuery(name)`, `amapUri(lng, lat, name)`（`https://uri.amap.com/marker?position=lng,lat&name=`）、`loadJSON(url)`
- sw.js：`CACHE_VERSION`，预缓存清单，同源 GET cache-first + 后台更新

**验证：** 本地 `python3 -m http.server` 打开两页不报 404；sw 注册成功（控制台无错误）。

## Task 2: 数据层

**Files:** data/trips.json, data/trips/xinjiang-2026.json, docs/data-format.md, tools/validate.mjs

**Produces:**
- trips.json：旅行索引，含 id/title/start/end/status/spotlight 坐标
- xinjiang-2026.json：13 天完整数据（timeline/food/shopping/prep/places/hotel/strength/highlights/scenery）
- validate.mjs：校验索引与行程文件一一对应、日期连续、dayIndex 连续、坐标 [number,number] 范围合理（中国境内）、字段类型

**验证：** `node tools/validate.mjs` 输出 PASS。

## Task 3: 主页（旅行列表 + 足迹）

**Files:** js/home.js, index.html, css/style.css

**Produces:** 渲染旅行封面卡（封面占位、标题、日期范围、天数、状态标签：计划中/进行中/已完成；进行中置顶并标注「今天 D+n」）；有 Key 时足迹地图（各旅行 spotlight 打点），无 Key 时显示足迹文字条。

**验证：** 手机视口渲染正常；点击卡片跳转 `trip.html?id=xinjiang-2026`。

## Task 4: 行程页划卡与 Tab

**Files:** js/trip.js, trip.html, css/style.css

**Produces:** 日期条（横向滚动、今天高亮、点击跳天）；横向 scroll-snap 日卡容器；日卡 = 日总览卡（起终点/住宿/驾驶时长/强度/亮点/路线图区）+ 三 Tab（行程=时间轴+沿途风景、美食=三餐+购物、准备=衣物/随身/门票提醒/贴士）；Tab 按内容有无自适应隐藏；进行中行程自动滚到今天。

**验证：** 13 天全部可滑、Tab 切换正常、空模块不渲染。

## Task 5: 地图模块（真实 + 降级）

**Files:** js/map.js

**Produces:**
- `initDayMap(container, places)`：四类标记（住宿蓝/景点橙/餐购红/换乘灰）+ 顺序连线 + InfoWindow（名称/地址/在高德打开）
- `initRouteMap(container, trip)`：全程住宿点连线
- `initFootprintMap(container, trips)`：各旅行打点
- 无 Key 或脚本加载失败：`renderFallback(container, places)` 有序地点条 + 逐点跳高德

**验证：** 有 Key（若用户提供）与无 Key 两种模式均正常；标记点击弹窗链接可唤起。

## Task 6: PWA 与收尾

**Files:** sw.js（版本号）、manifest、README.md（本地预览与 GitHub Pages 部署步骤）

**验证:** 浏览器手机模拟器无 console 错误；sw 缓存命中；校验脚本 PASS。

## Task 7: 端到端验证

- `node tools/validate.mjs`
- 本地起服务，用内置浏览器以手机视口截图：主页、行程页 D1、D4（内容最多）、D13、美食/准备 Tab
- 检查截图：字号、布局、滑动、Tab；修复问题后重新截图确认
- 最终 Git 提交
